## How to Add a New ADR

1. Create a new record: `docs/adr/XXXX-title-with-dashes.md`.
2. Follow the standard sections:
   - **Context:** Problem statement and user requirements.
   - **Alternatives Considered:** Options analyzed with pros and cons.
   - **Decision & Rationale:** Chosen architecture and key components.
   - **Consequences:** Positive benefits and trade-offs.
3. Update this index table.
